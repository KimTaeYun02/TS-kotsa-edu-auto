# TS 학습 도우미 1.6.1

한국교통안전공단 교육 영상을 일반 속도로 재생하고 완료 후 다음 차시로 이동하는 Chrome 119 이상 / Edge 확장 프로그램입니다. 배속 설정과 별도 End 요청 옵션을 제거했습니다.

## 설치와 업데이트

1. ZIP을 풀고 기존 `extension` 폴더의 파일을 교체합니다.
2. `chrome://extensions` 또는 `edge://extensions`에서 확장 프로그램을 새로고침합니다. 처음 설치할 때는 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 `extension` 폴더를 선택합니다.
3. **기존 영상 페이지도 새로고침**합니다. 이전 버전의 배속과 End 요청 타이머를 제거하기 위해 필요합니다.
4. 확장 아이콘에서 **모든 학습 탭에 JS 적용**을 누릅니다.
5. 영상 패널에서 **자동 시작**을 누릅니다. 자동 재생이 차단되면 사이트의 재생 버튼도 직접 눌러 주세요.

## 다음 차시 소리

새 영상 플레이어를 감지하면 재생 전에 볼륨을 0으로 설정하고 음소거합니다. 영상 메타데이터가 로드될 때도 다시 적용하여 차시 전환 직후 소리가 나오지 않도록 합니다. 계속 강제하지 않으므로 이후 사용자가 직접 볼륨을 조절할 수 있습니다. 자동 시작을 다시 누르면 다시 음소거합니다.

## 자동 넘기기

재생 시작 시 정상 속도인 1배로 설정합니다. 30초마다 영상 종료와 사이트의 완료 상태를 확인하여 둘 다 확인되면 다음 차시로 이동합니다. 다음 차시에서도 자동으로 재생을 시도합니다.

서버가 미완료로 응답하면 페이지를 유지합니다. 평가·설문이 필요한 응답이나 마지막 차시에서는 멈춥니다. 차시 내 여러 콘텐츠의 순차 이동은 지원하지 않습니다. **자동 중지**는 재생, 자동 넘기기, 활동 이벤트 전송을 중지합니다. 자동 재생 체크박스를 끄면 현재 재생은 유지하고 자동 동작만 끕니다.

사이트가 원래 수행하는 재생 시작·주기적 진행 저장·영상 종료 시 완료 요청은 그대로 실행됩니다. 확장 프로그램은 별도 End 요청을 보내거나 학습 시간을 변경하지 않습니다.

## 활동 유지 시도

사용자가 실제 마우스를 움직이면 사이트의 남은 세션 시간이 늘어난다는 관찰을 바탕으로 추가한 기능입니다. **활동 유지 시도**가 켜져 있고 자동 모드가 동작 중이면 30초마다 영상 요소에 일반 DOM `mousemove` 이벤트를 보냅니다. iframe 이벤트는 상위 문서에 자동으로 전달되지 않으므로, 접근 가능한 같은 사이트의 상위 문서에도 각각 보냅니다. 다른 도메인 상위 문서에 접근할 수 없으면 해당 문서는 건너뜁니다.

기본적으로 켜져 있으며 옵션을 끌 수 있습니다. 같은 탭의 다음 차시에도 설정을 기억합니다. 패널에서 시도 횟수, 마지막 시각, 이벤트를 보낸 문서 수를 확인할 수 있습니다.

**실제 OS 마우스 커서를 움직이지 않으며 클릭·키 입력·강제 포커스 이동은 하지 않습니다.** 코드가 만든 DOM 이벤트는 실제 사용자가 만든 입력과 구분됩니다. 사이트가 실제 입력만 인정하면 세션 시간이 연장되지 않습니다. 패널의 시도 횟수는 이벤트 전달 시도 기록이며 서버나 세션 타이머가 연장을 승인했다는 뜻이 아닙니다. 이벤트를 보내기 위한 별도의 네트워크 요청이나 세션 연장 API 호출은 없습니다.

브라우저가 비활성 탭의 타이머를 늦추거나 탭을 절전 상태로 전환하면 30초 주기가 지연될 수 있습니다. 화면 잠금·컴퓨터 절전이나 서버의 최대 세션 만료를 해제하는 기능은 아닙니다. 실제 사이트에서 남은 세션 시간이 늘어나는지는 검증하지 못했습니다.

## 진단과 지원 범위

팝업은 열린 탭 수를 확인하고 `https://edu.kotsa.or.kr/*`의 메인 문서와 iframe을 검사합니다. 패널에서 영상 위치, 다음 확인까지 남은 초, 사이트가 응답한 남은 학습 시간을 구분해 표시합니다. 수강 시간과 세션 만료까지 남은 시간은 서로 다른 값입니다.

제공된 Video.js 구조(`window.player`, `detailForm`, `cmptnNm`, `nextLsnSn`, `$.commandSubmit`)를 기준으로 구현했습니다. 사이트의 jQuery Ajax 이벤트를 관찰하며 요청·응답과 로그인 토큰을 변조하지 않습니다. 사이트 구조나 이벤트 처리 방식이 바뀌면 수정이 필요할 수 있습니다.

## 개발과 확인

외부 의존성 없이 Node.js 20 이상에서 실행합니다.

```sh
npm run check
npm test
```

모의 테스트는 일반 속도 복원, 30초 마우스 이벤트 전송, 같은 사이트 상위 문서 전달, 다른 도메인 예외, 활동 유지 해제와 자동 중지, 차시 이동 조건 및 제거한 기능의 부재를 확인합니다. 실제 사이트의 동작이나 세션 연장 성공을 보장하지 않습니다.

권한은 `scripting`, `webNavigation`, `https://edu.kotsa.or.kr/*`로 제한했습니다. 외부 서버 전송과 원격 분석은 없습니다.
